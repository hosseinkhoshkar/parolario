# Parolario

یادگیری واژگان ایتالیایی با راهنمای فارسی؛ PWA موبایل‌محور بر پایهٔ React، TypeScript و Vite. این نسخه از کد Wortzeit منشعب شده، اما هویت محتوا، ذخیره، قفل و cache مستقل دارد. حساب، بکاند و همگام‌سازی ندارد.

## محتوای فعال

درس اول **Primi contatti / نخستین آشنایی‌ها** از Nuovo Espresso 1 با **۸۵ مدخل منتخب** فعال است. همهٔ مدخل‌های [فایل واژگان](reference/vocabulary/italian/Lesson-01-A1.txt) پوشش دارند؛ این گزیده شامل تمام واژگان یا اعداد درس نیست. برای هر مدخل یک نمونهٔ نقل‌شده با ارجاع صفحه و دو مثال تألیفی با ترجمهٔ فارسی وجود دارد: مجموع۲۵۵ نمونه. نمونهٔ کتاب ممکن است عبارت، دستور تمرین یا بخشی پیوسته از متن باشد؛ در فایل مرجع مشخص شده است. مثال تألیفی به کتاب نسبت داده نمی‌شود.

درس دوم **Io e gli altri / من و دیگران** با **۹۲مدخل تازه** از [فایل درس دوم](reference/vocabulary/italian/Lesson-02-A1.txt) اضافه شده است: احوال‌پرسی، آشنایی، شغل، محل کار، زبان و سن. هر مدخل یک نقل واقعی و دو مثال تألیفی دارد؛ دو درس مجموع۱۷۷مدخل و۵۳۱نمونه دارند.۱۰تکرارِ هم‌معنی و هم‌نقش درس اول فقط ارجاع/occurrence جدید گرفته‌اند و پیشرفت تازه نمی‌سازند. اسمِ زبان و صفت ملیتِ هم‌شکل، با نقش و سرنخ مستقل مشخص‌اند.۹دهگان۲۰تا۱۰۰ از جدول کتاب آمده‌اند؛ این گزیده همهٔ عددهای مرکب یا کل کتاب را پوشش نمی‌دهد.

درس سوم **Buon appetito / نوش جان** با **۱۰۹مدخل تازه** از [فایل درس سوم](reference/vocabulary/italian/Lesson-03-A1.txt) افزوده شده است: سفارش غذا و نوشیدنی، وسایل میز و رزرو. صفحات۳۳تا۴۵ و تمرین‌های۱۵۸تا۱۶۲ به‌صورت تصویری بررسی شده‌اند. هر مدخل یک نمونهٔ کتاب و دو مثال تألیفی دوزبانه دارد؛ سه درس مجموع۲۸۶مدخل و۸۵۸نمونه دارند.۱۵تکرار درس۳ فقط ارجاع/occurrence هویت قبلی‌اند. برچسب تصویر و منو، عنوان و قطعهٔ متن به‌صراحت مشخص‌اند؛ این گزیده کل واژگان و غذاهای درس را پوشش نمی‌دهد.

کارت انتخاب درس، آمار و واژه‌نامهٔ مستقل و پیوندهای `?lesson=it-a1-lesson-01`، `?lesson=it-a1-lesson-02` و `?lesson=it-a1-lesson-03` فعال‌اند. جابه‌جایی درس‌ها جلسه، متن پاسخ و بازخورد را نگه می‌دارد. ترتیب فهرست و کارت‌های تازه بر اساس صفحهٔ چاپیِ ارجاع و ترتیب متن در همان صفحه است؛ فایل‌های درس۲و۳ نیز صفحه‌ای‌اند. افزودن درس۴به بعد به منبع و پذیرش جدا نیاز دارد.

## یادگیری

«ادامهٔ یادگیری» جلسهٔ ناتمام را بازیابی می‌کند. مرورهای موعدرسیده و دشواری‌ها پیش از حداکثر۵ واژهٔ تازه می‌آیند. ابتدا کارت‌های این دسته و سپس تمرین معنی، جای خالی، اتصال چهار جفت، نوشتن و آرتیکلِ قابل اعمال ارائه می‌شوند. پاسخ، موعد، صف، بازخورد و متن پاسخ با هم ذخیره می‌شوند؛ ثبت تکراری پاسخ دوباره شمرده نمی‌شود.

معنی، نوشتن و آرتیکل مهارت‌های جدا هستند. فقط یادآوری نوشتاری مستقلِ واجد شرایط مرور را جلو می‌برد؛ فاصله‌های۱،۳،۷،۱۴،۳۰روز و ادامهٔ بلندمدت. پس از تکمیل واقعی۱۵مدخل، حداکثر۲مرور معکوسِ موعدرسیده در جلسه‌های تازه قرار می‌گیرد. پاسخ ابتدا پنهان است؛ ارزیابی شخصی جدا از مهارت نوشتن ثبت می‌شود. چرخش مثال فقط با تکمیل مرور معکوس تغییر می‌کند.

هدف روزانه۲۰دقیقهٔ فعالیت واقعی است؛ توقف، صفحهٔ مخفی و بسته‌بودن برنامه حساب نمی‌شوند. ادامه بعد از هدف ممکن است و صف خالی می‌تواند زودتر تمام شود.

## ایتالیایی و تلفظ

متن و ورودی هدف LTR و lang=it هستند. اکسان‌ها حذف نمی‌شوند؛ آپاستروف صاف و خمیده و شکل‌های تایپی معادل یکسان سنجیده می‌شوند. سایر صورت‌های جایگزین فقط با تعریف صریح پذیرفته می‌شوند. آرتیکل فقط برای اسم با صورت معلوم است. il/lo/la/l'/i/gli/le پشتیبانی می‌شوند؛ جنسیت l' مستقل ثبت می‌شود. جمع نامعلوم ساخته نمی‌شود. برای اسم فاقد آرتیکل/جنس مستقلِ لازم، تمرین ساختگی ساخته نمی‌شود؛ نمونهٔ منبع و توضیح این محدودیت در جزئیات حفظ می‌شوند. مترادف‌های هم‌گروه مانند camera/stanza سؤال یا اتصال مبهم نمی‌سازند.

بلندگو و لمس متنِ زیرخط‌دار از Web Speech API با اولویت it-IT و سپس صدای ایتالیایی موجود، با سرعت ثابت۱ استفاده می‌کنند. پیش از نمایش پاسخِ مرور معکوس، صوت پاسخ وجود ندارد. سؤال آرتیکل فقط خود اسم و جای خالی فقط قسمت آشکار را می‌خواند. وجود صدا و پخش آفلاین آن به دستگاه بستگی دارد.

## ذخیره و آفلاین

قرارداد فعال schema۵ و محتوای `nuovo-espresso-a1-it-v1` است. IndexedDB با نام `parolario-progress` و قفل `parolario-single-writer` از نسخهٔ آلمانی مستقل‌اند. ذخیره‌های آلمانی/ناشناخته بدون بازنویسی یا reset رد می‌شوند؛ مهاجرت زبانی انجام نمی‌شود. دادهٔ سایت روی همین دستگاه و مرورگر است؛ پاک‌کردن دادهٔ سایت می‌تواند پیشرفت را از بین ببرد. پشتیبان خودکار وجود ندارد.

هویت نصب `/parolario`، نام برنامه Parolario و cache برابر `parolario-shell-<build>` است. آمادگی آفلاین فقط بعد از تأیید تمام منابع همان build نمایش داده می‌شود. آفلاین به localhost یا HTTPS نیاز دارد؛ حالت dev آمادگی آفلاین اعلام نمی‌کند.

## اجرا و بررسی

Node.js24:

```sh
npm ci
npm run sync:examples
npm run dev -- --host 0.0.0.0
npm test
npm run lint
npm run build
npm run verify:dist
npm run preview
npm run test:browser
```

اگر محیط اجرای فرایند build را منع کند، `npm run build:portable` همان برنامه را بدون کمینه‌سازی می‌سازد. تست مرورگر به Chromium نصب‌شده نیاز دارد؛ مسیر اختیاری آن `PAROLARIO_CHROMIUM_PATH` است. نتایج و محدودیت واقعی در [گزارش پذیرش درس سوم](docs/italian-lesson-three-acceptance.md)، [درس دوم](docs/italian-lesson-two-acceptance.md) و [سابقهٔ درس اول](docs/italian-lesson-one-acceptance.md) ثبت می‌شوند؛ تست مدل، SSR یا صدای شبیه‌سازی‌شده اثبات اجرای گوشی فیزیکی یا شنیدن واقعی تلفظ نیست.
